# Thumbnail Explorer

Windows 用のファイルブラウザーです。アプリ内の一覧でファイルとフォルダーを開き、ファイルやフォルダーごとにサムネイルを作成できます。

## 起動

`Release/ThumbnailExplorer.exe` を開きます。.NET 10 Desktop Runtime が必要です。配布する場合は `Release` フォルダー内のファイルをまとめてコピーしてください。

ソースから発行する場合は、.NET 10 SDK が入った環境で実行します。

```powershell
dotnet publish App/ThumbnailExplorer.csproj -c Release -o Release
```

## インストーラー

セットアップの利用方法とビルド方法は [Installer/README.md](Installer/README.md) を参照してください。

## 表示言語

起動時に Windows の表示言語を読み取ります。日本語の環境では日本語で表示し、英語およびその他の環境では英語で表示します。Windows の表示言語を変更した後はアプリを開き直してください。配布時は、実行ファイルと一緒に `ja` フォルダーもコピーしてください。

## ファイルを操作する

- 左側のナビゲーションには、よく使うフォルダーと PC のドライブが表示されます。矢印で下位フォルダーを展開できます。中央の一覧をダブルクリックするか、アドレス欄や「フォルダーを選ぶ」からフォルダーを開くこともできます。
- ファイルをダブルクリックすると、Windows で関連付けられたアプリが開きます。
- 複数選択には Ctrl または Shift を使います。ツールバーや右クリックメニューから、名前変更、新規フォルダー、コピー、切り取り、貼り付け、ZIP 圧縮ができます。別のフォルダーに移動するには、切り取ってから移動先で貼り付けます。
- 検索は表示中のフォルダー内の名前が対象です。並び替え、隠し項目、拡張子、ライト・ダーク・ベージュのテーマは上部で切り替えます。表示サイズはスライダーまたは Ctrl＋マウスホイールで変えられます。
- F2 で名前変更、F5 で更新、Ctrl＋L でアドレス欄、Ctrl＋F で検索欄に移動できます。ファイル一覧にフォーカスがあるときは Ctrl＋C／X／V を使えます。

## サムネイルを作る

中央の一覧でファイルまたはフォルダーを選択し、右側の編集画面で画像、文字、図形、手描きを組み合わせます。文字や図形はキャンバス上でドラッグして配置できます。文字はフォント・色・サイズ、図形は種類・色・幅・高さを調整できます。手描きにはペン、消しゴム、取り消しがあります。「保存」または Ctrl＋S で一覧に反映します。

登録内容と表示設定は `%LOCALAPPDATA%\ThumbnailExplorer` に保存されます。Windows 標準のエクスプローラーには反映されません。サムネイルはパスで管理されるため、このアプリからの名前変更・移動・コピーには追従し、外部アプリでパスを変更した場合は再登録が必要です。

シンボリックリンクやジャンクションを含むフォルダーのコピー・移動・圧縮には対応していません。
